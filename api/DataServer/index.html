DataServer

The server-side service for managing player data.

Types​

DataTemplate​

</>
type DataTemplate = {[string]: any}

Defines the structure of player data used by the DataServer.

local datatemplate = {
	currency = 0,
	inventory = {
		apples = 5,
		oranges = 10,
	},
	settings = {
		music = true,
	},
	items = {} :: { [string]: ItemData },
	array = {} :: { number },
}
NOTE

Player data automatically reconciles the template on join if new keys are added.

WARNING

Follow JSON rules for all data. (e.g., no Vector3, CFrame, etc.)

DataOptions​

</>
interface DataOptions {
template: DataTemplate--

Template dictionary for player data.

profileStoreIndex: string--

Index for the ProfileStore.

useMock: boolean?--

Use Mock data for testing.

viewedUserId: number?--

User ID to view data for. Use to view a specific player's data without saving.

overridenUserId: number?--

User ID to override for the profile. Use to play on another player's save.

dontSave: boolean?--

Prevent saving the profile. Use for testing without saving.

resetData: boolean?--

Reset the data on player join. Use to wipe data for testing.

}
local options = {
	template = require(path.to.datatemplate),
	profileStoreIndex = "Public",
}

Provides options for initializing the DataServer.

Functions​

startSessionAsync​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
DataServer:startSessionAsync(player: Player) → boolean

Loads the player's data, starting a ProfileStore session and making it available through server[player]. Idempotent: if the player is already loaded, it returns true immediately. 

local ok = Data.server:startSessionAsync(player)
if not ok then
	-- onSessionFail already fired
end

endSession​

</>
DataServer:endSession(player: Player) → ()

Ends the player's profile session: saves and releases it, removes Data.server[player], and fires onSessionEnd. Does not touch the Player instance or kick the player. 

Data.server:endSession(player)

resetData​

</>
DataServer:resetData(player: Player) → ()

Resets the data for the specified player by removing their profile from the store. The player is then kicked from the game with a message to rejoin. 

Data.server:resetData(player)

sendGlobalMessage​

</>
DataServer:sendGlobalMessage(
key: string,
userId: number | string,
data: {any}
) → boolean

Sends a global message to the specified user's profile. Returns true if the message was sent successfully, false otherwise. 

Data.server:sendGlobalMessage("SendGift", userId, { currency = 100, from = "Friend" })

addGlobalCallback​

</>
DataServer:addGlobalCallback(
key: string,
cb: (
player: Player,
data: {any}
) → boolean?
) → ()

Adds a global callback function for handling messages with the specified key. The callback receives the player and data as parameters. If the callback returns false, the message is not processed further. 

Data.server:addGlobalCallback("SendGift", function(player: Player, data: { any }): boolean?
	print("Received gift for", player.Name, "with data:", data)
	-- Process the gift here
end)

addPlayerRemovingCallback​

</>
DataServer:addPlayerRemovingCallback(fn: (
player: Player,
data: any
) → ()) → ()

Add any number of functions to be called when a player is removed. Used to perform cleanup or save data before the player leaves. 

Data.server:addPlayerRemovingCallback(function(player: Player, data: any): ()
	print(player.Name .. " is leaving with data:", data)
	-- Perform any cleanup or save operations here
end)

local disconnect = Data.server:addPlayerRemovingCallback(function(player: Player, data: any): ()
	data.currency = 0
end)

-- Later, you can disconnect this function if needed
disconnect()

waitForData​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
DataServer:waitForData(player: Player) → Data?

Waits for the player's data to be initialized and returns it. If the data is already available, it returns immediately. Returns nil if the player leaves before their data loads.

asyncGetProfile​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
DataServer:asyncGetProfile(userId: number | string) → Profile?

Asynchronously retrieves the profile for the given user ID using internal ProfileStore.

getProfile​

</>
DataServer:getProfile(player: Player) → Profile?

Retrieves the profile for the given player.

get​

</>
DataServer:get(
player: Player,
should_assert: boolean?
) → value.value<T>?

Returns the player's reactive data root. Pass true to error if the player's data is not loaded yet.

Prefer :get(player) over indexing server[player] directly.

-- returns nil if not loaded
local playerData = Data.server:get(player)
if playerData then
	playerData.currency(50)
end

-- errors if not loaded
local playerData = Data.server:get(player, true)
playerData.currency(50)

isLoaded​

</>
DataServer:isLoaded(player: Player) → boolean

Returns whether the player's data has been loaded and is available through server[player].

if Data.server:isLoaded(player) then
	print(Data.server[player].coins())
end
